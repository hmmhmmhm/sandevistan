## Reproduced defects and fixes

1. **SDK audio fixture no longer typechecked.** `AudioEvent` now includes
   `direction` and `speakerRole`. The test models an unavailable direction and
   unknown role, preserving the existing audio forwarding behavior.
2. **Checkbox meaning reversed after icon update.** The older package's
   workaround swapped checked/empty names; 1.2.6 corrected those assets.
   Restored direct semantic mapping and verified the checked glyph in the
   rendered SVG. The regression test failed before the mapping fix.
3. **JSON byte limit applied after full buffering.** A chunked request could
   consume unbounded memory before `readLimitedRequestJson` rejected it.
   Reused streaming byte limits and cancel on overflow. The regression test
   failed on the original implementation and passed after the fix.
4. **Development API buffered every request without a cap.** Non-API requests
   now pass directly to Vite. API bodies stop at 32,000 bytes (the largest
   existing route limit); body and request-construction failures are caught.
   Added tests for early termination, non-API passthrough, and an actual HTTP
   connection receiving 413.
5. **Private RSS hostname checks accepted trailing dots and bare hosts.**
   `localhost.`, `reader.local.`, and `printer` reached the injected upstream
   before the fix. Normalize trailing dots for validation and reject bare
   hostnames. The phone now also rejects `.internal`, `.home`, and `.lan`,
   matching the server policy. Added failing-then-passing client/server tests.
6. **Vite warmup referenced missing `src/main.jsx`.** Corrected the configured
   entry to the existing `src/main.tsx`.

## Remaining gates and findings

- **Physical G2:** repeat startup, both-eye image display, paging, details,
  hide/restore, Ask AI entry/exit, microphone cleanup, and Conversate on
  Even App >=2.2.10. SDK 0.0.16 has not been physically approved. The previous
  compressed-image instability is not established as fixed.
- **Browser UI:** CUA inventory reported that local browser use is disabled in
  Work settings. No page was opened and no fresh screenshot or interactive
  browser result is claimed. HTTP checks do not execute the client UI.
- **Initial bundle:** Vite still warns about a roughly 1.95 MB minified JS
  chunk (about 603 KB gzip). Code splitting needs a separate change and
  phone/WebView validation; the warning was not suppressed.
- **RSS network boundary:** hostname filtering does not validate resolved IP
  addresses or prevent DNS rebinding. A public hostname resolving to a private
  address still needs an egress/DNS policy for a publicly hosted multi-user
  deployment. No internal network probe was performed.
- **Live providers:** no OpenAI/ORS key was supplied, so authenticated calls
  were tested using controlled fixtures. The 540-feed catalog was unchanged;
  a new full live RSS sweep was not run.
- **Runtime warning:** Node 25 emits a localStorage warning in jsdom tests;
  all tests pass. A supported LTS Node run is an additional environment gate.

All temporary HTTP servers were closed. No browser tab or Blender instance
was started for this audit.
