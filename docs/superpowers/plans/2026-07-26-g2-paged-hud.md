# G2 Paged HUD Implementation Plan

> Historical plan. Its instructions and checkboxes do not establish current completion.
> See the [documentation index](../../index.md) for scope and evidence.
> The current main-only workflow supersedes historical branch and worktree instructions.
> Historical commit and publication steps require current owner authorization.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the non-navigation news overview the default and distribute the dense HUD across four circular pages controlled by G2/R1 scroll events.

**Architecture:** Keep one 576×288 Canvas and the proven four image containers. The renderer accepts a typed page name. `App` owns the circular page index. `transmitCanvas` serializes each redraw and four-tile update in one promise queue without rebuilding containers.

**Tech Stack:** TypeScript, React 19, HTML Canvas 2D, Vitest, Vite, Even Hub SDK `0.0.10`

- [ ] **Step 4: Extract a reusable tile refresh**

Inside `transmitCanvas`, define:

```ts
const refreshImages = async (completionMessage: string) => {
  const encodedTiles = await dependencies.encode(source, undefined, tiles);
  await sendTilesSequentially(encodedTiles, async (bytes, index) => {
    const tile = tiles[index];
    const result = ImageRawDataUpdateResult.normalize(
      await bridge.updateImageRawData(new ImageRawDataUpdate({
        containerID: tile.id,
        containerName: tile.name,
        imageData: bytes,
      })),
    );
    if (!ImageRawDataUpdateResult.isSuccess(result)) {
      throw new Error(`${tile.name} transmission failed: ${result}`);
    }
    onProgress(`Transmitting glasses image ${index + 1}/${tiles.length}`);
  });
  onProgress(completionMessage);
};
```

Use `await refreshImages("Glasses transmission complete")` for the initial frame.

- [ ] **Step 5: Add the direction callback and serial event queue**

Export:

```ts
export type PageDirection = "next" | "previous";
```

Add the optional fifth argument:

```ts
onNavigate?: (direction: PageDirection) => void | Promise<void>,
```

After initial transmission, keep:

```ts
let navigationQueue = Promise.resolve();
const queueNavigation = (direction: PageDirection) => {
  navigationQueue = navigationQueue
    .then(async () => {
      onProgress("Switching HUD pages");
      await onNavigate?.(direction);
      await refreshImages("Page transfer complete");
    })
    .catch((error: unknown) => {
      onProgress(error instanceof Error ? error.message : String(error));
    });
};
```

Use the event type from `sysEvent` first and `textEvent` second. Bottom queues
`next`, top queues `previous`, and double-click retains shutdown behavior.
